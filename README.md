# Bhraman Saathi

Frontend-only prototype for Smart India Hackathon 2026 (PS 26204).

Bhraman Saathi is a smart tourism ecosystem connecting tourists, hotels, travel agencies, and local businesses.

This repository currently contains the **frontend foundation** only: Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui, and brand design tokens. Product pages are not built yet.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint
